# Birthday Website ♡

Website ucapan ulang tahun romantis.

## File
- index.html = struktur website
- style.css = desain
- script.js = animasi & interaksi

## Cara menjalankan
Klik dua kali `index.html`, atau buka menggunakan Live Server di VS Code.

## Yang akan kita personalisasi
1. Nama/panggilan
2. Foto kalian
3. Lagu
4. Surat/ucapan
5. Warna & tema
6. Animasi tambahan
